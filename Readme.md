# 🌦️ Live Weather App with GUI
# Description:
A beautiful desktop weather application built with **Python**, featuring a modern **Tkinter** GUI and real-time weather data fetched from the **OpenWeatherMap API**. 🚀

---

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Display temperature, feels like, humidity, wind speed, and pressure
- ⛅ Real-time weather icons and conditions
- 🕒 Shows local time and date
- 💻 Clean, responsive GUI with dark theme
- 💖 Built using Python, Tkinter, Pillow, and Requests

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (for GUI)
- Requests (for API call)
- Pillow (for image handling)
- OpenWeatherMap API
